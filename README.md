# IntelliStock-Smart Inventory Management System with basic demand forecasting
The Smart Inventory Management System with Basic Demand Forecasting is a user-friendly web application developed to help small and medium-sized businesses manage their inventory more effectively. It allows users to
easily track products, monitor stock levels, and record sales transactions through an interactive interface built using Streamlit and SQLite.
By analyzing past sales data with Simple Linear Regression, the system can predict future demand, estimate
when stock may run out, and provide timely low-stock alerts. In addition, it uses the Apriori algorithm to identify products that are frequently purchased together and offers reports and visualizations that support smarter business decisions.
